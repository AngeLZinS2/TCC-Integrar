# FASE P2 — EMPLOYEE EXPERIENCE, COMUNICAÇÃO, DOCUMENTOS E AUTOMAÇÕES

Você agora deve implementar a FASE P2 da plataforma SaaS de Integração Corporativa.

==================================================
PRÉ-REQUISITO
==================================================

A FASE P0 e a FASE P1 devem estar concluídas e validadas antes de iniciar esta fase.

Antes de alterar qualquer arquivo:

1. verificar o estado atual do projeto;
2. verificar se P0 está funcionando;
3. verificar se P1 está funcionando;
4. executar os testes existentes;
5. verificar migrations;
6. verificar git status;
7. analisar a arquitetura atual.

NÃO assumir que funcionalidades da P0/P1 existem apenas porque estavam previstas.

Se alguma parte estiver incompleta, informe antes de continuar.

==================================================
OBJETIVO DA P2
==================================================

Transformar a plataforma de:

"Onboarding + Treinamentos"

em:

"Employee Experience + Comunicação + Gestão de Solicitações + Documentos + Automação"

Nesta fase devem entrar:

1. Solicitações de RH;
2. Comunicados;
3. Eventos;
4. Aniversariantes;
5. Documentos corporativos;
6. Upload seguro de arquivos;
7. Versionamento documental;
8. Aceite/obrigatoriedade de documentos;
9. Questionários de treinamento;
10. Nota mínima;
11. Certificados;
12. Notificações por e-mail;
13. Push quando houver infraestrutura;
14. tarefas de onboarding;
15. automações;
16. fila assíncrona;
17. Redis/Celery;
18. unidades da empresa;
19. melhoria do modelo organizacional.

NÃO implementar nesta fase:

- planos;
- cobrança;
- assinatura;
- marketplace;
- IA;
- SSO;
- SAML;
- SCIM;
- API pública;
- Webhooks externos;
- pesquisas de clima;
- avaliação de desempenho completa;
- recursos Enterprise avançados.

==================================================
HIERARQUIA DO SISTEMA
==================================================

Manter:

PLATFORM OWNER
    │
    ├── Empresa A
    │     ├── Administrador
    │     ├── RH
    │     ├── Gestor
    │     └── Colaborador
    │

REGRA ABSOLUTA:

Nenhum recurso novo pode quebrar o isolamento Multi-Tenant.

Toda informação pertence a uma Company, direta ou indiretamente.
